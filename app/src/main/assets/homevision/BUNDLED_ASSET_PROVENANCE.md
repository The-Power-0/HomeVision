# HomeVision bundled resource provenance

HomeVision derives from DataVision (`ayumilove/DataVision`), which derives from
TV Bro (`truefedex/tv-bro`). Some of the bundled browser interface assets were
inherited unchanged from DataVision. The original TV Bro copyright, source
license, and additional redistribution conditions remain applicable. See
`TV_BRO_LICENSE.md` and `ATTRIBUTION.md` in this directory.

The following resources were inherited unchanged from DataVision as verified
by Git blob hash comparison:

- Seven **search-engine logos**: Bing, Google, Yahoo, DuckDuckGo, Startpage,
  Yandex, and the inherited generic custom-search image.
- Five SVG interface illustrations/icons, including search, microphone, menu,
  image-placeholder and certificate-warning graphics.
- Ten Android nine-patch tab background image resources.
- `generic_injects.js`, a browser interaction helper inherited unchanged
  from DataVision (DataVision modified TV Bro's earlier version).

**Search-engine logos and brand names belong to their respective owners.**
Their presence in upstream source does not independently establish rights to
redistribute each company's mark or prove an endorsement. The origin and
licenses of individual inherited illustrations and tab images require further
review before unrestricted public redistribution.

or authorization to use these marks**. For the tracked Git blob IDs, review
`docs/HOMEVISION_INHERITED_ASSETS.csv` in the HomeVision source repository.
